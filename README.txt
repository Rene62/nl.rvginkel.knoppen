Dashboard Buttons

With Dashboard Buttons, you can easily create your own buttons for a Homey Dashboard. Use the buttons to start a Flow or to display or change the status of a Yes/No variable.

You decide which buttons you need, what text is displayed on them, and how wide they are displayed. You can combine multiple buttons in a single widget and arrange them in any order you like. A button can be displayed in multiple widgets.

An Action button starts a Flow and can pass a custom Action value. This value is available in the Flow as a text tag. For example, you can use multiple buttons with a single Flow and use the Action value to determine which action should be performed.

A Yes/No button is linked to a Homey Yes/No variable. The button displays the current status of the Yes/No variable with a green or red indicator. When you press the button, the Yes/No variable can be changed using a Flow.

With Flow cards, you can also enable or disable a button and temporarily display a colored light loop around the button. This allows you to show on the dashboard that an action has been performed or to draw attention to something.

Dashboard Buttons gives you the freedom to create a compact control panel that fits your own Homey setup.


After installing the app, go to the app settings. Here you create your buttons and choose a button type: Action or Yes/No. For a Yes/No button, select the corresponding Homey Yes/No variable. Then add the widget to your Homey Dashboard. In the widget settings, choose which buttons are displayed and in which order.
