Con Botones del Dashboard puedes crear un panel de control compacto para tu Dashboard de Homey. Crea botones reutilizables de Acción y Sí/No, combínalos en distintos widgets y muestra el estado desde Homey Logic, Better Logic o valores gestionados mediante Flow.

Usa los botones para iniciar Flows y ofrecer una respuesta visual clara con indicadores de estado, bordes de color y efectos de luz. Como el mismo botón puede aparecer en varios dashboards, tus controles se mantienen coherentes en toda tu instalación de Homey.
